Gestor de Fotos

Python 3.8+ • Tkinter • Pillow • imagehash

Descricao

Aplicacao desktop em Python para organizacao de bibliotecas fotograficas. O projeto junta deteccao de imagens repetidas, edicao de data EXIF e ferramentas em lote numa interface unica e simples de usar.

O objetivo e reduzir tarefas manuais e permitir que o utilizador valide alteracoes com pre-visualizacao antes de executar mudancas em ficheiros.

Stack e Estado

  • Python 3.8+
  • Tkinter (GUI desktop)
  • Pillow, imagehash, OpenCV
  • Status: concluido
  • Licenca: uso pessoal e comercial

Funcionalidades Principais

  • Duplicados: deteccao por MD5 (exatos) e perceptual hash (similares).
  • Agrupamento: grupos por similaridade com threshold configurado no codigo.
  • Pre-visualizacao: comparacao lado a lado antes de eliminar.
  • Datas: leitura e edicao de datas EXIF e timestamps de ficheiro.
  • Lote: renomeacao, redimensionamento e organizacao por data.
  • Performance: cache local para acelerar rescans.

Como Executar

Instalacao de dependencias:

pip install -r requirements.txt

Arrancar menu principal:

python main.py

Modos diretos:

python main.py duplicates python main.py exif python main.py batch_tools
